# Bank Loan Data Analysis and Visualization Pipeline

An end-to-end data analytics project focused on cleaning, transforming,
analyzing, and visualizing bank loan data to uncover meaningful business insights.

## Objectives

- Analyze total loan amounts
- Compare loan approval and rejection rates
- Identify branches with higher loan amounts
- Analyze credit scores across different cities
- Study the relationship between interest rates and loan amounts

## Data Cleaning

- Standardized inconsistent categorical values
- Handled missing values
- Corrected invalid credit scores
- Fixed negative loan amounts
- Handled outliers using the IQR method
- Removed duplicate records

## Data Transformation

- Extracted Year, Month, and Quarter from date fields
- Created analysis-ready features for reporting and visualization

## Data Visualization

The project includes visualizations for:

- Loan Status by City
- Loan Status Distribution
- Average Interest Rate by Branch
- Total Loan Amount by Branch
- Average Credit Score by City
